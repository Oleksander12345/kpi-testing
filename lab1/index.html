Основні елементи інтерфейсу web-сторінки

На цій сторінці наведено 10 поширених UI-елементів, їх приклади та коротке пояснення призначення. Усі демонстраційні елементи працюють без додаткових бібліотек.

1

Radiobutton

Перемикач для вибору лише одного варіанта з групи взаємовиключних опцій.

2

Checkbox

Прапорець для незалежного ввімкнення або вимкнення однієї чи кількох опцій.

3

Text input

Поле для введення однорядкового тексту, наприклад імені, пошукового запиту або назви.

4

Tabs

Вкладки організовують пов’язаний контент у кілька секцій і дозволяють перемикатися між ними без переходу на іншу сторінку.

Це вміст вкладки «Опис».
Тут можуть бути характеристики продукту або сервісу.
Тут може бути контактна інформація.
5

Button

Кнопка запускає дію: надсилання форми, збереження даних, відкриття діалогу тощо.

6

Text label

Текстова мітка пояснює призначення поля або іншого елемента. Атрибут for пов’язує label із полем вводу.

7

Link

Посилання використовується для переходу на іншу сторінку, сайт або до окремої секції документа.

Відкрити MDN Web Docs
8

Tooltip

Спливаюча підказка показує додаткову коротку інформацію при наведенні курсора або фокусі.

Наведіть курсор на цей текст Tooltip допомагає пояснити елемент без перевантаження інтерфейсу. .
9

Dropdown list

Випадаючий список дозволяє вибрати один варіант із заздалегідь визначеного набору значень.

10

Data grid

Таблична сітка відображає структуровані дані у рядках і стовпцях. Часто використовується для списків користувачів, товарів, задач, тест-кейсів або звітів.
